# WPD (Web Page Design) -- Headphones Landing Page

An early static HTML/CSS coursework project: a product landing page for a headphones brand ("Betrax"). No JavaScript -- pure HTML/CSS layout practice.

An improved, later iteration of the same design (with JS interactivity added) lives at [betrax-studio-3](https://github.com/AaryanKoradia/betrax-studio-3).

## View it

Open `Betrax - Headphones/index.html` directly in a browser -- no build step or server needed.
